GitHub Revisando…

Para que tus pendientes de Claude sigan el cambio solos (unido, publicando y listo) y para que tú o Alma puedan unir un cambio sin entrar a GitHub.

  1. Abre github.com → nueva llave. Nombre: Alma pendientes. Vence: 1 año.
  2. En Repository access elige All repositories. En Permissions elige Read and write en Pull requests y Contents (para unir), y Read-only en Checks, Commit statuses y Actions (así Alma ve también si ya se publicó).
  3. Toca Generate token, cópialo y pégalo aquí.
