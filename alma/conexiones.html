GitHub Revisando…

Para que tus pendientes de Claude desaparezcan solos cuando unes el cambio. Es una llave de solo lectura.

  1. Abre github.com → nueva llave. Nombre: Alma pendientes. Vence: 1 año.
  2. En Repository access elige All repositories. En Permissions → Pull requests elige Read-only.
  3. Toca Generate token, cópialo y pégalo aquí.
