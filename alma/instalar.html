«Alma aquí»

Abre a Alma desde cualquier página, con la página como contexto: «¿qué dice este PR?», «resúmeme esto», «¿a quién le reenvío esto?».

iPad y iPhone · desde «Compartir» (recomendado)

Funciona en todos los sitios, incluidos GitHub y Google.
  1. Abre la app Atajos y toca + para crear un atajo nuevo.
  2. Toca el nombre de arriba y ponle Alma. En ⓘ Detalles, activa Mostrar en hoja de compartir y deja solo URL y Páginas web de Safari.
  3. Busca la acción Abrir URL y agrégala.
  4. En la URL escribe https://hub.spacioam.com/alma/?desde= y, justo después, toca la variable Entrada del atajo.
  5. Listo. En Safari: Compartir → Alma.

Computadora · marcador

Arrastra este botón a la barra de marcadores. En cualquier página, tócalo y Alma se abre en otra pestaña con esa página (y lo que tengas seleccionado).
Alma aquí

También sirve en Safari del iPad: guarda cualquier página como marcador, edítalo y pega este código en la dirección.
